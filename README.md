## What this is

One dad joke, the whole entry:

> I put my savings in the blender. Now my money is liquid.

Why this joke: it is the kind a real dad actually says out loud at the breakfast table. Short, simple, one pun (liquid money), straight face, instant groan. Not a famous joke copied from a list, so it is not a copy of anyone else's entry.

## How it works

`main.py` (Python 3.13, no network, deterministic) writes the joke to `/output/entry.txt`.

```bash
python3 main.py
```
